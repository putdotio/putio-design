# App icons

`app-icon-source.png` is the 1024×1024 squircle source for iOS, macOS, Android, and web. Flavor masters: `app-icon-prod-dark.png` (production), `app-icon-dev-blueprint.png` (dev, blueprint blue), `app-icon-nightly-stars.png` (nightly and staging). Prod and dev are pixel art: scale them nearest-neighbour. Nightly is not: scale it smoothly. `app-icon-beta.png` is a deprecated compatibility asset; new integrations use the standard icon.
