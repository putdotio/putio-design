## Using this system

Change the system in [putdotio/putio-design](https://github.com/putdotio/putio-design), not here: this artifact is generated from that repository, and the next publish overwrites edits made on this page. Product code installs `@putdotio/design` (`@putdotio/design/css` for tokens, `@putdotio/design/components` for the web recipes).

GT America and Berkeley Mono are licensed and load only from `static.put.io`, which these previews can't reach; Inter and JetBrains Mono stand in. The platform contracts follow as their own sections. Motion tokens (`--dur-*`, `--ease-*`) live in `bundle.css`.
