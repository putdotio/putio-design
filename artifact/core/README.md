put.io is a quiet, content-agnostic file browser. Dark by default.

- Show filenames exactly as stored.
- Neutrals do the work. `--yellow-solid` is the brand fill, one primary per group.
- GT America for UI; Berkeley Mono for numbers and filenames. TV product UI has no mono; debug overlays may use the system monospace.
- Phosphor icons; file-type icons are yellow.
- Lists and rows before cards. Auth pages have no card: logo top-left, one 340px column on the page.
- Field and form errors ease in as red text (`.form-reveal`, `--dur-reveal`); never a boxed callout in a form.

Change it in [putdotio/putio-design](https://github.com/putdotio/putio-design). Full rules: [DESIGN.md](https://github.com/putdotio/putio-design/blob/main/DESIGN.md).
