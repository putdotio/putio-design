Navigation — a Home hub, no persistent chrome
TV navigation is a stack with the header hidden — there is no tab bar and no floating top nav. The first screen is Home: a hub whose body is a plain list of destination rows (Your Files · Search · History · Account). Selecting a row pushes a full screen; the remote Back button pops it. Every screen shares one anatomy — a header (the logo on Home, a title elsewhere) over a list of rows.
