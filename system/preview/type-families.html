02 — Mono · Berkeley Mono numerics, timestamps, code, logs, identifiers
/usr
For machines and makers.
Berkeley Graphics·2020·Programming
The designer-preferred programming monospace, and now the only mono in the system. Crisp at 12px, distinct 0/O and 1/l/I, no accidental ligatures, and strong tabular figures — so it carries transfer speeds and file sizes as cleanly as it carries a magnet URI. Never body copy.
