Sort & action menus — centred select modal
Every TV menu is the same centred modal — never a popover anchored to its trigger. A full --overlay-full scrim covers the screen; the panel sits on --app-bg with a 1px --line border, 32px padding, and width 25% (max 50%). Title is 36px --text-secondary. Rows are transparent until focused, then --component-bg-active — the same fill every focusable TV surface uses. Destructive rows read --red-text-secondary at rest and fill --red-solid when focused, but the label stays --text — focus resets the text colour regardless of destructive. Default focus is the row matching the current value, else the first row.
Sort list · option filtering
Six sort keys × two directions = twelve options, filtered down per current value. An option survives if it shares the current key or the current direction — so the current value itself is kept and checked, and the opposite direction of the current key is kept and carries a chevron disclosure. Every other key appears once, in the current direction, with no icon. For NAME_ASC that is seven rows, shown below.

The two name-direction rows intentionally share the Name label; the checked state and chevron communicate their different actions.

Long-press file actions · same modal, different contents
Long-OK or right arrow on a row opens the same select modal, titled with the raw filename. Items are filtered by capability, so the set is never fixed: Play in VLC only when a stream URL exists and the VLC scheme is installed; Mark as watched / unwatched only for non-shared videos with start-from enabled; Trash (or Delete when the account has trash off) for anything not shared. If nothing qualifies, no menu opens at all.
