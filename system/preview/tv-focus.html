Focus — a fill, never a lift
TV focus is one treatment everywhere: the surface fills with --component-bg-active. No scale, no shadow, no halo, no white-invert — on every surface put.io draws. The one exception is the tvOS system player, which Apple draws and which uses its own white-invert focus idiom; see the player card.Rows take the fill alone; chrome (header action buttons) takes the fill and steps its border from --border to --border-hover, because a button already carries a border at rest. Label and icon stay --text in both states. Source: list-item.tsx · button.tsx.

Platform variation · implementation, not redesign
The visual is identical across all four TV platforms — every column below is the same value, because list-item.tsx and button.tsx are cross-platform React Native and specify no per-platform divergence. Only the engine drawing the state differs. Focus is applied instantly: pressable.tsx is a bare re-export of RN's Pressable with a style function of focused — there is no Animated, no timing curve, and theme.pressable.tvParallaxProperties sets enabled: false.
