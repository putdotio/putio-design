01 Horizontal tabs — radix segmented Tabs.tsx
Inset pills with --segmented-control-bg-active for the selected tab on a --line tray. Default size is 32px; sm is 28px for dense areas. Use for 2–5 mutually-exclusive views.
02 Underline tabs — content navigation
Use within a page when the tabs swap large content regions. Yellow underline marks the active tab; counts ride at the right of the label.
03 Vertical tabs — settings detail
For long settings flows. Active item uses --nav-item-bg-active (step 3) with a yellow icon. The right pane scrolls independently.
