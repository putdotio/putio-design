# Design Docs

This public repo owns the design-system materials that can be published with
`putio-design`: tokens, generated package artifacts, the deployed guide, and
safe preview material.

- [DESIGN.md](../DESIGN.md) — concise design contract for humans and AI agents
- [Distribution](DISTRIBUTION.md) — deploy, package, and artifact policy
- [Design system guide](../system/README.md) — deployed guide structure and token usage
- [Token sources](../tokens) — canonical DTCG-compatible token JSON
- [Generated outputs](../dist) — CSS, JSON, TypeScript, and Figma-safe artifacts

Keep this repo focused on the public design-system guide, tokens, preview cards,
deployable design-site assets, generated galleries, and raw visual experiments.
Private product conclusions, research, plans, decisions, references, and
moodboards stay outside this public repo unless they are intentionally sanitized
for publication.
