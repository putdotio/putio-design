# putio-design

Design system for [put.io](https://put.io) — tokens, components, and design documentation for every platform put.io lives on.

## Structure

```
docs/
  design.md          — master design document (personas, needs, principles, audit)
  assets/            — screenshots and reference images
```

## Platforms

Apple TV · iOS · Android · Android TV · Fire TV · Roku · Web · watchOS · visionOS

## Context

put.io is a cloud storage and transfer service with a cult following and no dedicated designer in 15+ years. This repo is where that changes.

Start with [`docs/design.md`](docs/design.md).
