---
name: tv-apps-file-browsing
description: TV apps must use file browsing interface, not media card grids — put.io has no metadata
type: feedback
---

TV apps should have a file browsing interface, not a Netflix-style card grid. put.io is content-agnostic — there are no posters, no metadata, no album art. The current TV app is a list of folders and files with yellow folder icons, and that's correct.

**Why:** put.io doesn't control the content. Users upload whatever — videos, music, documents, archives. File names are messy. There are no movie posters to lean on. Designing a media-card grid assumes metadata that doesn't exist.
**How to apply:** Always check existing screenshots before designing platform screens. TV screens should use list views with folder/file hierarchy, not card grids with thumbnails. Typography and spacing do the work, not imagery.
